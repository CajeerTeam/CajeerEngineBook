# Возможности платформы

[Обзор](README.md) · [Рабочие сценарии](workflows.md) · [Релизы](../releases/README.md)

В таблицах приведены возможности, присутствующие в исходном дереве Book `1.2.0`. Для отдельных функций нужны конфигурация, внешние сервисы или дополнительные операционные проверки.

## Контент и редактура

| Возможность | Что реализовано | Важные условия |
| --- | --- | --- |
| Markdown и визуальный редактор | Черновики, rich text, таблицы, блоки кода | Поддерживаемый синтаксис определяется редактором Book |
| Структура документации | Дерево страниц, порядок, перенаправления, версии | Изменения опубликованных материалов проходят проверку прав |
| Компоненты | Callout, карточки, вкладки, шаги, интерактивные блоки, Mermaid | Произвольные исполняемые MDX/React-компоненты не запускаются |
| Медиа | Библиотека изображений, вложения и проверка содержимого | Требуется приватное постоянное хранилище |
| Переводы | Локализованные версии страниц и маршруты | Перевод и ревью выполняет команда |
| Ревью и история | Запросы на согласование, версии документа, журнал активности | Права задаются ролями и политиками рабочих пространств |

## Публикация и Developer Experience

| Возможность | Как используется | Граница поддержки |
| --- | --- | --- |
| Reader | Отображение опубликованной документации | Видимость и разрешения проверяются сервером |
| Поиск | Полнотекстовый поиск, опциональные embeddings и гибридная выдача | Embeddings требуют отдельного провайдера; при его недоступности остаётся обычный поиск |
| OpenAPI и Playground | Документация операций и тестирование поддерживаемых API | Только разрешённые серверы и прокси-источники |
| SDK и примеры | Формирование и публикация примеров клиентов | Проверяйте применимость к целевому API |
| GitHub / GitLab Sync | Импорт, синхронизация и предложения изменений | Конфликты требуют явного решения; действует авторизация проекта |
| CI/CD Publishing | Подготовка и подтверждение публикационных сборок | Токены, согласование и аудит регулируют процесс |
| Статический экспорт | Формирование переносимой документации | Проверьте поддержку динамических возможностей перед переходом |

## Импорт и миграция

| Источник | Поддерживаемые данные | Что проверить после импорта |
| --- | --- | --- |
| Markdown | Страницы, ссылки, медиа | Структуру, пути и видимость |
| [Mintlify](../admin/mintlify-import.md) | `docs.json`, `mint.json`, статические MDX-блоки | Динамический JSX не переносится |
| [Docusaurus](../admin/docusaurus-import.md) | Sidebars, версии, локали, статические элементы MDX | Навигацию, версии, ссылки |
| [GitBook](../admin/gitbook-import.md) | Spaces, Git Sync, `SUMMARY.md`, поддерживаемые блоки | Права, redirects, удалённые медиа |
| [ReadMe](../admin/readme-import.md) | Guides, Reference, Recipes, OpenAPI | Интерактивные компоненты и внешние изображения |
| [Fumadocs](../admin/fumadocs-import.md) | Content Collections, `meta.json`, локали | Динамический MDX, нестандартные компоненты |

**Общий принцип:** импорт использует предварительный просмотр и подтверждение изменений, не должен автоматически делать документы публичными и не исполняет недоверенный JavaScript из источника.

## Администрирование и расширения

| Подсистема | Возможности | Условия |
| --- | --- | --- |
| IAM | Локальные учётные записи, роли, организации, рабочие пространства, OIDC / SkiF4er ID | Не выдаёт повышенные роли по факту внешнего входа |
| Аналитика | Агрегация просмотров, поиска и целей; опциональные провайдеры | Сбор и внешние теги зависят от согласия и настроек |
| AI-помощник | Подсказки редактору, чат на основе разрешённой документации | Передача контента внешним API только при включении; нужен обзор приватности |
| Надёжность | PostgreSQL 16, Redis, Sentinel, реплики, приватные медиа | HA и failover зависят от инфраструктуры |
| Операции | Метрики, аудит, бэкапы, PITR, диагностические команды | Настраиваются отдельно и регулярно проверяются |
| Обновления | Подписанные GitHub Releases, панель владельца, host-agent | Запуск `Apply` под контролем оператора; не unattended |

Для выбора топологии: [развёртывание](deployment.md). Для ограничений безопасности: [безопасность и данные](security.md). Точные переменные и процедуры — в [руководстве администратора](../admin/README.md).
